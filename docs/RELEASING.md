# Release & privacy checklist

This repo is PUBLIC and doubles as our marketplace storefront. Before every push:

- [ ] No credentials, tokens, keys, wallet material, or secrets of any kind
- [ ] No internal hostnames, paths, repo names, project codes, or team/person names
- [ ] No internal jargon - write for an external developer audience
- [ ] No operational data that could identify private infrastructure
- [ ] Skill examples run standalone with no private dependencies
